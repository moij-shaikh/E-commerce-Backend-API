# E-commerce Backend API

A backend API for an e-commerce application built with Python and FastAPI.

## Features

- User registration and login
- JWT authentication
- Product management
- Shopping cart
- Checkout
- Order management
- Admin endpoints
- Redis caching
- Email verification
- Database migrations

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Redis
- JWT
